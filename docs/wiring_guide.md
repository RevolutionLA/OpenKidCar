## 1. 电源系统（最优先，安全接线）

```
锂电池组 24V +BAT ──► [保险丝 20A] ──► 电调 电源输入＋
锂电池组 24V -BAT ───────────────────► 电调 电源输入－

电调输出的电机→直流电机（正反按需要调换）
电调信号线(白/橙) ──► Arduino D9（油门）
电调电源输出 ──► DC-DC 降压 24V→5V ──► 树莓派 5V + Arduino 5V
```

### ✅ 关键安全点
1. **保险丝紧贴电池正极**，短路先断保险丝再烧设备。
2. **树莓派和 Arduino 都由 DC-DC 5V 供电**，不要用 USB 同时供电（隔离）。
3. 电池回路**务必用粗线**（电机电流大），信号线用细线。

## 2. 大脑 ↔ 小脑通信（树莓派 ↔ Arduino）

```
树莓派 GPIO14(TXD) ──► 电平转换 L1 ──► Arduino Mega D19 (RX1)
树莓派 GPIO15(RXD) ◄── 电平转换 L1 ◄─── Arduino Mega D18 (TX1)
树莓派 GND ────────────► 电平转换 GND ◄─ Arduino GND （共地！）
```

> ⚠️ **必须用双向电平转换模块**：Arduino 5V → 树莓派 3.3V 方向转换，否则烧树莓派 GPIO。
> ⚠️ **共地必须连**，否则串口不通。

## 3. Arduino 输出接线（执行器 + 灯）

| Arduino 引脚 | 接什么 | 说明 |
|---|---|---|
| **D9** | 电调信号线 | 电机油门 |
| **D10** | 舵机信号线 | 转向（后续实现，见 §7） |
| **D2** | 经 MOS 继电器 → 前大灯 | 大电流隔离 |
| **D3** | 刹车灯（LED 串电阻）| 亮度 PWM |
| **D4** | 左转向灯（串电阻）| |
| **D5** | 右转向灯（串电阻）| |
| **D11** | WS2812B 灯带数据线 | RGB（需 NeoPixel 库） |

> 灯直接串一个 220Ω 电阻接 GND，或用 MOS 继电器驱动大灯/灯带。

## 5. 一键急刹双保险（安全红线，必须做）

你的固件已实现软件急刹（D22 + EBRK 命令）。为达到硬件级安全，**额外加一层**：

```
急刹按钮一面 ──► Arduino D22（软件急刹，已有）
急刹按钮另一面 ──► 电调使能/电源使能端（硬件直连断电）
```

这样即使程序故障，按下急刹物理切断动力。

## 6. 接线总览图（一句话版本）

```
电池24V ├─►保险丝→电调→电机
        └─►DC-DC 5V→树莓派 + Arduino

树莓派[TXD/RXD]─电平转换→Arduino[D19/D18]   ←串口协议
Arduino[D9→电调] [D10→舵机] [D2,D3,D4,D5→灯] [D11→灯带]
Arduino[A0,A1,A2,A3,A4,A5→踏板/坐垫/电压/温度/电流]
Arduino[D22-D27→六键]
```

## 7. ⚠️ 转向和轮速（当前待开发）

这两项在固件里还是**占位/待补**：

1. **转向**：当前只有 `TURN`(转向灯) 命令，**没有 STEER(转向执行) 命令**。接线可以先把舵机接 D10，但驱动代码需要我补。
2. **轮速传感器**：`estimate_speed()` 用的是"油门×档位估算"，**不是真实速度**。要做速度闭环和档位限速，需要接霍尔/编码器到 Arduino，并新增 STAT 上报真实速度。

> 这两项（STEER 命令 + 轮速采集）是我接下来要帮你写的固件部分。接线先留在对应引脚即可。

## 8. 常见错误（接线前必看）

| 错误 | 后果 | 避免 |
|---|---|---|
| 共地没连 | 串口收不到数据 | 树莓派/Arduino/电平转换 GND 全连 |
| 24V 直连树莓派 | 🚨烧毁 | 只走 DC-DC 5V |
| A3 直连 24V | 烧 ADC | 必须分压 |
| 电机线直连 GPIO | 烧 Arduino | 走电调 |
| 电平没转换 | 烧树莓派 | 必须用转换模块 |

## 9. 验证清单（第一步：桌面静态验证，不坐人）

按顺序测，确认无误再上电：

| # | 测试 | 预期 |

| 1 | 电池→保险丝→电调 | 电调上电滴声 |
| 2 | 电平转换接好 | 树莓派能看到 Arduino READY |
| 3 | 电机转动 | 电调信号接 D9，Arduino 输出 → 电机转 |
| 4 | 急刹按钮 | 按下 → 电机停 |
| 5 | 大灯/灯带 | 网页/按钮控制亮灭 |
| 6 | 油门踏板 | A0 读数变化 → 电机变速 |
