## V0.1：电子原型验证（AI 驾驶舱 Demo）🟡 开发中

**目标：** 在桌面完成 Pi ↔ Arduino 通信与基础电子控制验证。

| 模块 | 内容 |
|------|------|
| 通信 | Raspberry Pi ↔ Arduino Mega 自定义协议通信 |
| 显示 | OLED 仪表盘（速度/电量/档位模拟） |
| 灯光 | LED 灯带控制（开关/颜色/亮度） |
| 输入 | 按键矩阵（模拟油门/刹车/中控按钮） |
| 音效 | 功放模块验证（PWM 油门 → 频率变化发声） |
| 语音 | 唤醒词"干杯出来"本地识别 Demo |

**验收标准：** 桌面原型可演示：语音唤醒 → 控制 LED + OLED 响应 + 模拟油门发声。

---

## V0.2：核心驾控系统

**目标：** 接入真实动力系统，实现可驾驶的底盘。

| 模块 | 内容 | 关联 PRD |
|------|------|----------|
| 动力 | 电机选型 → 电调匹配 → 电池选型 | [F-DRV-01/02] |
| 油门 | 左脚霍尔踏板 → Arduino ADC → PWM 调速 | [F-DRV-01] |
| 刹车 | 右脚霍尔踏板 → 电调刹车 + 机械刹车预留 | [F-DRV-02] |
| 转向 | 方向盘/手柄 → 转向电机/舵机 | [F-DRV-03] |
| 档位 | Arduino 端速度上限控制（4 档可切换） | [F-DRV-04] |
| 刹车 | 一键急刹物理按钮 → 最高优先级制动 | [F-DRV-05] |
| 电源 | 电池管理系统、总电源开关 | [F-BAT-02/05] |

**验收标准：** 在简易底盘上实现驾驶、转向、刹车、4 档限速。

---

## V0.3：智能座舱

**目标：** 完成中控台、灯光系统、音响系统的完整集成。

| 模块 | 内容 | 关联 PRD |
|------|------|----------|
| 中控 | 物理控制面板（静音/大灯/灯带/喇叭/急刹） | [F-CON-01~05] |
| 大灯 | 前 LED 大灯 + 尾灯 + 刹车灯 | [F-LIT-01/03] |
| 灯带 | RGB 灯带环绕车身 + 多模式切换 | [F-LIT-02] |
| 音响 | 功放 + 扬声器 + 引擎声浪合成算法 | [F-SND-01/02/04] |
| 静音 | 物理静音开关 | [F-SND-03] |
| 上下电 | 坐垫压力传感器 → 自动上电/延时关机 | [F-PWR-01/02] |

**验收标准：** 中控所有按钮功能正常；灯光系统完整运行；引擎声浪随油门变化。

---

## V0.4：互联智能

**目标：** 完成 APP、语音助手、GPS、对讲、摄像头全链路打通。

| 模块 | 内容 | 关联 PRD |
|------|------|----------|
| 4G 通信 | Pi + 4G 模块 → MQTT 云端 | - |
| 家长 APP | Flutter 开发：定位/对讲/档位/电量/远程刹车 | [F-APP-01~07] |
| GPS | GPS 模组 → 云端上报 → APP 地图显示 | [F-GPS-01] |
| 对讲 | APP ↔ Pi ↔ 车内麦克风+扬声器 实时语音 | [F-TLK-01/02] |
| 语音 | 唤醒词"干杯出来"→ 本地离线识别 + 云端 NLP | [F-VOI-01~04] |
| 摄像 | 前置摄像头 + 翻转机构 → 行车记录 + vlog | [F-CAM-01~03] |

**验收标准：** APP 可远程控制档位、查看位置、实时对讲；语音助手可控制灯光。

## V0.5：车体与防水集成

**目标：** 完成真实车体制造、防水密封、整车组装。

| 模块 | 内容 | 关联 PRD |

| 布线 | 整车线束设计与防水接插件 | [F-BAT-03] |
| 外壳 | 外观设计 + 涂装 + 贴花 | - |

**验收标准：** 完整车体，淋水测试通过，电池仓可放头盔。
