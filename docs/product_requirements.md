# 干杯一号 — 产品需求文档

> OpenKidCar 项目首款智能儿童卡丁车

---

## 1. 产品概述

| 项目 | 说明 |
|---|---|
| **产品名称** | 干杯一号（Ganbei No.1） |
| **产品定位** | AI 驱动的智能儿童卡丁车 |
| **目标用户** | 3-8 岁儿童 + 家长 |
| **驱动方式** | 电动后驱 / 双电机驱动 |
| **开发理念** | 开源、模块化、家长可控、安全第一 |

---

## 2. 使用场景

1. **日常兜风** — 孩子在小区/公园安全驾驶，家长 APP 实时监控
2. **亲子互动** — 家长通过 APP 与车内孩子实时对讲
3. **Vlog 记录** — 行车记录仪自动记录驾驶画面，翻转可自拍 vlog
4. **语音交互** — 孩子通过语音唤醒控制灯光、音效等功能

---

## 3. 功能需求

### 3.1 操控系统

| 编号 | 功能 | 描述 | 优先级 |
|------|------|------|--------|
| F-DRV-01 | 油门控制 | 左脚油门踏板，踩下加速，松开减速 | P0 |
| F-DRV-02 | 刹车控制 | 右脚刹车踏板，踩下制动 | P0 |
| F-DRV-03 | 转向控制 | 方向盘/手柄控制前轮转向 | P0 |
| F-DRV-04 | 速度档位 | 家长 APP 设置 4 档速度上限 | P0 |
| F-DRV-05 | 一键刹车 | 中控台物理按钮，按下立即最大制动 | P0 |

| 档位 | 速度范围 | 适用场景 |
|------|----------|----------|
| 一档 | 0–10 km/h | 初学者 / 室内 |
| 二档 | 0–15 km/h | 熟练驾驶 |
| 三档 | 0–20 km/h | 开放场地 |
| 四档 | 0–25 km/h | 赛道模式 |

## 4. 非功能需求

| 编号 | 类别 | 要求 |
|------|------|------|
| NF-01 | 安全性 | 刹车响应时间 ≤ 200ms；一键刹车优先级最高 |
| NF-02 | 防水 | 车身 IP65，电控仓 + 电池仓 IP67 |
| NF-03 | 续航 | ≥ 1 小时连续驾驶（正常路面） |
| NF-04 | 通信延迟 | 对讲延迟 ≤ 500ms；远程制动延迟 ≤ 1s |
| NF-05 | 重量 | 整车 ≤ 35kg（便于成人搬运） |
| NF-06 | 载重 | 最大载重 50kg |

## 6. 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 电机选型不当 | 动力不足/过快 | 先用计算器验算，再实车测试 |
| 电池安全 | 起火/爆炸 | 选用品牌锂电池 + 保险丝 + 温度监控 |
| 防水失效 | 电路短路 | 分仓密封 + 每仓独立排水测试 |
| 语音误唤醒 | 非预期动作 | 唤醒后需二次确认敏感操作 |
| 通信断连 | 远程功能失效 | 本地控制不受影响；断连后自动降速 |
