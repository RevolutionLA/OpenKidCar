## 采购优先级建议

| 阶段 | 先买 | 说明 |
|---|---|---|
| **核心验证**（优先） | 树莓派、Mega、电平转换、电源、杜邦线 | 先跑通"树莓派↔Arduino 通信 + 数字孪生" |
| **动力**（第二步） | 电机、电调、电池、DC-DC | 车能动起来 |
| **干杯助手**（并行） | USB 麦克风、USB 音箱 | 对话 |
| **扩展**（后期） | 4G/GPS、灯带、传感器 | P0 功能 |

## 接线总览

```
电池 12V ─┬─► 电调 ─► 电机
           └─► DC-DC 5V ─► 树莓派 + Arduino

树莓派 GPIO14/15 ─(电平转换)─► Arduino D19/D18   [UART 通信]
树莓派 USB ─► USB 麦克风 + USB 音箱              [干杯助手对话]
树莓派 3.5mm ─► 功放 ─► 扬声器                   [引擎声/喇叭/对讲]
Arduino A0-A5 ─► 踏板/坐垫/电压/温度/电流        [传感输入]
Arduino D22-27 ─► 按钮                           [按键输入]
Arduino D2-5,9-11 ─► 灯/转向/电调/舵机/灯带      [执行输出]
```

> 详细引脚说明见 [hardware_io_map.md](hardware_io_map.md)，部署步骤见 [hardware_deployment_guide.md](hardware_deployment_guide.md)。
