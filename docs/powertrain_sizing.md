# 动力系统选型计算书 —— 干杯一号

> 文档状态：**首版草案**（2026-08-11）
> 适用于：从零自建车架与动力（路 B）
> 说明：本计算书给出电机 / 电池 / 电调 / 减速的选型依据。所有数字都可复核、可调整。

---

## 0. ⚠️ 最大前提：安全优先

**给 3 岁孩子造载人电动车，以下红线不可妥协：**

1. **电池必须是有认证的锂电池组 + 配套 BMS 保护板**，禁止用散装电芯自行组装（火灾风险）。
2. **电池回路必须串接保险丝/断路器**，短路即断电。
3. **电机功率和车速必须匹配孩子年龄**。你选择维持 25km/h 上限，这是 8 岁+ 儿童的水平。给 3 岁孩子，我们**通过档位软件限制**强制更低（见 §5），硬件按上限预留即可。
4. **刹车系统必须有机械可靠性**，不能只依赖电子制动。
5. 整车电气采用**低压 24V**，但仍需防短路、防倾翻、接线绝缘。

## 1. 计算前提（输入参数）

| 参数 | 符号 | 取值 | 说明 |
|---|---|---|---|
| 车身重量 | m_车身 | 25 kg | 钢管/铝架，不含电池 |
| 电池重量 | m_电池 | ≈ 5 kg | 24V 电池 |
| 孩子体重 | m_孩子 | 15 kg | 3 岁孩子典型 |
| **满载总重** | m | **45 kg** | 25+5+15 |
| 车轮直径 | D | 14 寸 ≈ 0.356 m | 半径 r ≈ 0.178 m |
| 重力加速度 | g | 9.8 m/s² | |
| 最大设计车速 | v_max | 25 km/h = 6.94 m/s | 四档（硬件上限） |
| 最大坡度 | θ | 5%（sinθ≈0.05） | 缓坡 |
| 滚动阻力系数 | μr | 0.015 | 硬质路面 |
| 空气阻力系数×面积 | Cd·A | ≈ 0.4 m² | 儿童车近似 |
| 传动系统效率 | η | 0.8 | 链/齿减速 |
| 电池电压 | V | 24 V | |

---

## 2. 需求阻力计算

### 2.1 滚动阻力（始终存在）
```
Fr = μr × m × g = 0.015 × 45 × 9.8 = 6.6 N
```

### 2.2 坡度阻力（上坡时）
```
Fg = m × g × sinθ = 45 × 9.8 × 0.05 = 22.1 N
```

### 2.3 空气阻力（高速时）
```
Fd = 0.5 × ρ × Cd·A × v²
   = 0.5 × 1.2 × 0.4 × 6.94² ≈ 11.6 N   (25 km/h)
```

---

## 3. 所需电机功率

**功率 = 力 × 速度 ÷ 效率**

### 3.1 平路巡航（25 km/h）
```
P_平路 = (Fr + Fd) × v / η
      = (6.6 + 11.6) × 6.94 / 0.8
      ≈ 158 W
```

### 3.2 上坡（5%，按 10 km/h = 2.78 m/s 爬坡）
```
P_上坡 = (Fr + Fg) × v / η
      = (6.6 + 22.1) × 2.78 / 0.8
      ≈ 100 W
```

### 3.3 结论 —— 电机功率
- **持续额定功率 ≥ 160 W（平路巡航）**
- 考虑起步加速峰值，选 **额定 ≥ 200 W，峰值 ≥ 250 W** 的电机

> **建议选型：24V 直流减速电机，额定 200~250 W，峰值 ≥ 250 W。**

---

## 4. 减速比与电机转速

### 4.1 车轮最高转速
车轮线速度 25 km/h → 轮转速：
```
n_轮 = v / (2πr) = 6.94 / (2 × 3.14 × 0.178)
    = 6.2 rps = 372 RPM
```

### 4.2 电机转速与减速比
常见 24V 直流电机额定 3000~4000 RPM。取电机 3700 RPM：
```
减速比 i = 3700 / 372 ≈ 10
```

> **建议：减速比约 10:1**（可用齿轮箱电机，或链条/皮带减速）

---

## 5. 扭矩验证（能否起步）

### 5.1 起步/爬坡所需车轮扭矩
```
T_轮 = F₁×r / η
F₁(满载上坡起步) ≈ Fr + Fg + 启动余量
                ≈ 6.6 + 22.1 + 15 ≈ 43.7 N
T_轮 = 43.7 × 0.178 / 0.8 ≈ 9.7 N·m
```

### 5.2 折算到电机轴扭矩
```
T_电机 = T_轮 / i = 9.7 / 10 ≈ 0.97 N·m
```

> 200W、3700RPM 电机的额定扭矩约 0.5 N·m，峰值约 1.0~1.2 N·m。
> **结论：减速比 10:1 + 200~250W 电机，起步/爬坡正好覆盖，略有余量。** 建议减速比取 **11~12:1** 以增裕度。

---

## 6. 电池容量（续航 1 小时）

### 6.1 平均电流估算
平均行驶功率按峰值巡航的 40~60%（加减速、走走停停）：
```
P_avg ≈ 100 W
I_avg = P_avg / V = 100 / 24 ≈ 4.2 A
```

### 6.2 容量
```
续航 1h → 4.2 Ah
加 1.3 安全系数 → ≈ 5.5 Ah
```

> **建议：24V ≥ 10 Ah**（留足余量，实际续航约 1.5~2 小时）。常见 24V 12Ah。

---

## 7. 电调（ESC）选型

- **必须双向**（支持倒车 R 档）
- 电流 ≥ 电机峰值电流。200W/24V 峰值约 10~12A，**选 ≥ 15A 连续、≥ 25A 峰值**
- 输入 24V，输出到电机
- 常见：双向有刷电调（如电调能输出反转），或带反转功能的电机驱动板

## 9. ⚠️ 转向系统重要说明（当前痛点）

当前固件**只有 TURN（转向灯）命令，没有 STEER（转向执行）命令**。真车转向需要：

1. **新增 STEER 协议命令**（大脑→小脑下发方向盘角度）
2. **舵机/转向电机控制**落地（`hal_mega.cpp` 中 PIN_STEER = D10 目前是 `analogWrite` 占位，需改 Servo 库输出）
3. 物理转向机构（舵机驱动前轮转向拉杆）

这部分是**固件 + 机械**双缺口，是我下一步要帮你补的软件部分。

## 10. 分阶段建议（结合你"从零搭"决定）

| 阶段 | 内容 | 目的 |
|---|---|---|
| **S1 桌面静态验证** | 电机/电调/电池单独接好，Arduino 直连控制，**不坐人** | 先证明动力和控制安全可靠 |
| **S2 无载试车** | 空车 (无人) 低速跑 | 验证机械传动、刹车 |
| **S3 低速载人** | 一档≤10km/h 试坐 | 逐步增大信心 |
| **S4 全档位** | 逐步开放 2/3/4 档 | 确认孩子可驾驭 |

> ⚠️ **强烈建议先不要直接上 25km/h。** 第一阶段只开放一档(10km/h)，确认一切稳妥后再逐步放开。
