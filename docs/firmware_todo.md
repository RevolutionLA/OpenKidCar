## 🔴 高优先级（不补，真车动不起来）

### 1. 电机控制真实化（ESC 信号）—— ✅ 已完成
- **改动**：`hal_mega.cpp` 的 `hal_set_motor()` 从 `analogWrite` 改为 **Servo 库**输出 50Hz、1000-2000µs 脉宽（1500=停，负=倒车）。D9 电调接 ESC。
- **验证**：mega2560 编译通过（需 `lib_deps` 加 `arduino-libraries/Servo`，已写入 platformio.ini）。
- **遗留**：真车上电后需做 ESC **油门行程校准**（不同电调微调中位/满量程）。

### 2. WS2812B 灯带驱动 —— ⏳ 待做
- **现状**：`hal_set_strip()` 仍是空的 `TODO`（P2 功能，可后置）。
- **需要**：接 `Adafruit_NeoPixel` 库，把 mode/color/brightness 落地到 D11。
- **影响**：不修，灯带不亮。

### 3. 舵机转向实现（STEER 命令）—— ✅ 已完成
- **改动**：
  - 协议新增 `STEER` 下行命令（参数 0-180 角度，90=直行）
  - `commands.h` + `commands.py` 两端加常量
  - `brain.py` 加 `set_steer(angle)` 方法
  - `main.cpp` 加 STEER 处理分支 + 测试钩子 `test_get_steer`
  - `hal_mega.cpp` 用 Servo 库驱动 D10 转向舵机
  - `twin_server.py` `RealCerebellum.set_steer` 把方向盘(-1..1) 映射成舵机角度下发
- **验证**：mega2560 编译通过；Python 端 smoke test 通过；`test_frame.cpp` 新增 STEER 边界用例。
- **遗留**：前端方向盘联动已在仿真链路（状态含 steer），真机联调时确认角度正翻。

## 🟠 中优先级（涉及速度闭环与安全）

### 4. 轮速传感器 + 真实速度测速 —— ✅ 已完成（待硬件标定）
- **改动**：
  - `hal.h` 新增 `int hal_read_speed_kph(void)`（轮速接口）
  - `hal_mega.cpp`：D21 外部中断统计霍尔脉冲 → 换算 km/h；`hal_sim.cpp` 用油门估算模拟
  - `main.cpp` `estimate_speed()` 改用真实轮速；`drive_motor()` 加入**档位限速闭环**（轮速接近上限线性收油、超速断油）
- **验证**：mega2560 编译通过。速度闭环逻辑在 `hal_sim` 可演示。
- **遗留**：真车上需按实际**轮径 + 每圈脉冲数**标定 `WHEEL_TICKS_PER_REV` / `WHEEL_CIRCUM_M`；确认 D21 引脚与实车传感器接线。

### 5. ADC 标定（P1-1）—— ⏳ 待真机
- **现状**：A0-A5 的电压/温度/电流换算仍是估算系数。
- **需要**：上板后用已知电压/温度/电流实测，逐个标定 `adc_to_*` 函数。
- **影响**：不标定，电量/温度/电流显示不准，过流过温保护是虚的。
