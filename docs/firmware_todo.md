# 固件待开发清单 —— 从仿真到真车（软件部分）

> 文档状态：首版（2026-08-11）
> 这是"真车动起来前，固件/软件还需要补哪些"的清单。按优先级排序，每项都能独立推进。

---

## 🔴 高优先级（不补，真车动不起来）

### 1. 电机控制真实化（ESC 信号）
- **现状**：`hal_mega.cpp` 的 `hal_set_motor()` 用 `analogWrite` 占位。`analogWrite` 输出约 490Hz 的 PWM，**不适用于电调（ESC 需 50Hz、1000-2000µs 脉宽）**。
- **需要**：改用 **Servo 库**（或定时器输出）产出 50Hz 脉宽信号到 D9。代码注释里已提示，但未实现。
- **影响**：不修，电调收不到正确油门信号，电机不转。

### 2. WS2812B 灯带驱动
- **现状**：`hal_set_strip()` 是空的 `TODO`。
- **需要**：接 **Adafruit_NeoPixel 库**，把 mode/color/brightness 落地到 D11。
- **影响**：不修，灯带不亮（P2 功能，可后置）。

### 3. 舵机转向实现（STEER 命令）
- **现状**：协议里**没有 STEER 命令**，固件 `handle_command` 也没有转向分支；`hal_set_steer` 是 `analogWrite` 占位。
- **需要**：
  - 协议文档新增 `STEER` 下行命令（角度 0-180 或 -100~100）
  - `commands.h` + `commands.py` 两端加常量
  - `brain.py` 加 `set_steer()` 方法
  - `hal_mega.cpp` 用 Servo 库驱动 D10
  - 前端控制区关联方向盘
- **影响**：不修，车不会转向。

## 🟠 中优先级（涉及速度闭环与安全）

### 4. 轮速传感器 + 真实速度测速
- **现状**：`report_status()` 里 `estimate_speed()` 用"油门×档位估算"，**不是真实速度**。
- **需要**：接霍尔/编码器到轮子，Arduino 统计脉冲算真实速度，STAT 上报，并用真实速度做档位限速。
- **影响**：不做速度闭环，档位限速(安全功能)是假的。

### 5. ADC 标定（P1-1）
- **现状**：A0-A5 的电压/温度/电流换算用的是"拍脑袋"系数。
- **需要**：上板后用已知电压/温度/电流实测，逐个标定 `adc_to_*` 函数。
- **影响**：不标定，电量/温度/电流显示不准，过流过温保护是虚的。

## 🟡 低优先级（功能增强）

### 6. 坐姿检测→自动上下电
- **现状**：`RealCerebellum.set_seat()` 是占位。
- **需要**：A2 压力传感 + 电源继电器管理逻辑。
- **影响**：P1 功能，可后置。

### 7. 4G/GPS 真机对接
- **现状**：`gps_lat=39.9087` 是模拟值。
- **需要**：接 SIM7600/二合一，替换模拟 GPS，打通远程控制/对讲。
- **影响**：P0 功能（远程定位/对讲），但可放到整车动力稳定后再做。

## 开发顺序建议

```
第1步：ESC 电机控制真实化（Servo）→ 车能转电机
第2步：舵机转向 STEER 命令 → 车能转向
第3步：轮速闭环 → 档位限速真实
第4步：ADC 标定 → 电量/保护真实
第5步：灯带/坐姿/4G → 智能功能
```

> 每一步都能在测试环境验证后再上真车。建议配合 `powertrain_sizing.md` §10 的分阶段试车一起推进。
