# 通信协议 V0.2

本文档定义 OpenKidCar「干杯一号」大脑（Raspberry Pi）与小脑（Arduino Mega）之间的串口通信协议。

> 这份协议是"接口契约"的一部分，与 [hardware_io_map.md](hardware_io_map.md) 配套。两端代码必须严格按此实现。

---

## 1. 物理层

| 参数 | 值 |
|---|---|
| 通信接口 | UART 串口 |
| 波特率 | 115200 |
| 数据格式 | 8 数据位 / 无校验 / 1 停止位（8N1） |
| 接线 | 树莓派 GPIO14/15 ↔ Arduino Serial1 (D18/D19) |
| 电平 | ⚠️ Arduino(5V) → 树莓派(3.3V) 方向必须经双向电平转换模块 |

---

## 2. 帧格式

协议采用**可读文本行**格式，每帧以换行 `\n` 结尾：

```
#命令:参数;校验:XX\n
```

| 字段 | 说明 |
|---|---|
| `#` | 帧头，标志一帧开始 |
| `命令` | 命令名，大写字母（见第 3 节） |
| `:参数` | 参数，冒号分隔命令与参数；多个参数用逗号 `,` 分隔；无参数可省略 |
| `;校验:XX` | 校验段，`XX` 为十六进制两位校验和（见 2.1） |
| `\n` | 帧结束符 |

### 2.1 校验算法

对 `命令:参数`（不含 `#`、`;`、校验本身）的所有字符做 **XOR 逐字节累加**，结果为 1 字节，格式化为大写十六进制两位。

示例：命令 `LIGHT:ON`

```
字符  L    I    G    H    T    :    O    N
ASCII 4C   49   47   48   54   3A   4F   4E
XOR   ^    ^    ^    ^    ^    ^    ^    ^
结果  4C^49=05 → 05^47=42 → 42^48=0A → 0A^54=5E → 5E^3A=64 → 64^4F=2B → 2B^4E=65
```

校验和 = `65`，完整帧：

```
#LIGHT:ON;CK:65\n
```

### 2.2 解析规则

1. 接收方逐字符读取，遇到 `#` 开始缓冲
2. 读到 `\n` 结束缓冲，得到一帧
3. 检查帧头、拆出命令与参数、重算校验
4. 校验通过 → 解析执行；校验失败 → **静默丢弃**该帧

## 3. 命令集

### 3.1 下行命令（大脑 → 小脑）

| 命令 | 参数 | 含义 | 示例 |
|---|---|---|---|
| `GEAR` | 1-4 | 设置速度档位 | `GEAR:3` |
| `LIGHT` | ON / OFF | 前大灯 | `LIGHT:ON` |
| `STRIP` | 模式,颜色,亮度 | RGB 灯带 | `STRIP:1,FF0000,100` |
| `TURN` | L / R / OFF | 转向灯 | `TURN:L` |
| `MUTE` | ON / OFF | 引擎音效静音 | `MUTE:ON` |
| `HORN` | ON / OFF | 鸣笛 | `HORN:ON` |
| `BRAKE` | ON / OFF | 制动（缓刹） | `BRAKE:ON` |
| `EBRK` | ON | 远程急刹（最高优先级） | `EBRK:ON` |
| `STATUS` | GET | 请求状态上报 | `STATUS:GET` |
| `PING` | - | 心跳请求 | `PING` |

### 3.2 上行命令（小脑 → 大脑）

| 命令 | 参数 | 含义 | 示例 |
|---|---|---|---|
| `STAT` | 速度,油门,档位,电压,温度,电流 | 状态上报 | `STAT:12,55,3,24.6,32,3.2` |
| `BTN` | 按钮名,PRESS/RELEASE | 按钮事件 | `BTN:LIGHT_BTN,PRESS` |
| `SEAT` | ON / OFF | 就座 / 离座 | `SEAT:ON` |
| `EBRK` | ON | 急刹被触发 | `EBRK:ON` |
| `PONG` | - | 心跳响应 | `PONG` |
| `ACK` | OK / ERR:原因 | 命令应答 | `ACK:OK` |
| `READY` | - | 小脑上电就绪 | `READY` |

### 3.3 按钮名清单（BTN 命令参数）

| 按钮名 | 对应硬件 | 说明 |
|---|---|---|
| `LIGHT_BTN` | D24 大灯开关 | 切换大灯 |
| `MUTE_BTN` | D23 静音开关 | 切换静音 |
| `STRIP_BTN` | D25 灯带开关 | 切换灯带 |
| `HORN_BTN` | D26 喇叭按钮 | 按下=PRESS，松开=RELEASE |
| `EBRK_BTN` | D22 一键刹车 | 自锁按钮，PRESS |
| `TALK_BTN` | D27 对讲按钮 | 按住说话=PRESS，松开=RELEASE |

## 4. 通信流程

### 4.1 上电握手

```
小脑 ──READY──► 大脑         （小脑上电完成，通知大脑）
大脑 ──GEAR:2──► 小脑         （大脑下发当前档位，状态同步）
大脑 ──LIGHT:ON─► 小脑        （下发当前灯光状态，状态同步）
```

### 4.2 心跳机制

- 大脑每 **1 秒** 发一次 `PING`，小脑立即回 `PONG`
- **连续 3 次**未收到 `PONG` → 大脑判定小脑离线，进入**安全模式**：
  - 若在行驶中 → 平滑减速至停止
  - 通过 4G 通知家长 APP
- 小脑若超过 **5 秒**未收到任何 `PING` → 小脑判定大脑离线，进入**安全兜底**：维持当前安全状态，若在行驶中平滑减速至停止

### 4.3 正常交互示例：按下大灯按钮

```
① 小脑检测到 LIGHT_BTN 按下
② 小脑 ──BTN:LIGHT_BTN,PRESS──► 大脑
③ 大脑 解析：灯当前是关 → 切换为开
④ 大脑 ──LIGHT:ON──► 小脑
⑤ 小脑 执行：D2 继电器闭合 → 大灯亮起
⑥ 小脑 ──ACK:OK──► 大脑     （执行成功）
```

### 4.4 引擎轰鸣的音效数据流

```
① 小脑 以 10Hz 定时上报油门深度
② 小脑 ──STAT:12,55,3,...──► 大脑
③ 大脑 根据"油门=55%"实时合成引擎音效
④ 大脑 通过音频输出 → 功放 → 扬声器播放（油门越大越响）
⑤ 若 MUTE_BTN 按下 → 小脑上报 → 大脑静音所有音源
```

## 5. 错误处理

| 情况 | 处理 |
|---|---|
| 校验失败 | 静默丢弃该帧，不回复 |
| 未知命令 | 回复 `ACK:ERR:UNKNOWN` |
| 参数非法 | 回复 `ACK:ERR:INVALID_ARG` |
| 小脑离线（3 次心跳无响应） | 大脑安全模式 + APP 通知 |
| 大脑离线（5 秒无 PING） | 小脑安全兜底减速 |

## 6. 数据上报说明

### 6.1 状态上报频率

- 行驶中：**10Hz**（100ms 一次）
- 静止且无人：**1Hz**（省电）

### 6.2 STAT 参数顺序

```
STAT:速度,油门,档位,电压,温度,电流
      12 , 55 , 3 , 24.6, 32 , 3.2
```

| 参数 | 单位 | 来源 |
|---|---|---|
| 速度 | km/h | 轮速传感器 / 油门档位估算 |
| 油门 | % | A0 霍尔踏板 |
| 档位 | 1-4 | 当前限速档位 |
| 电压 | V | A3 分压采样 |
| 温度 | ℃ | A4 NTC |
| 电流 | A | A5 霍尔电流传感器 |

## 7. 扩展机制

- **新增命令**：在命令表（第 3 节）增加一行，两端同步实现，协议版本号 +0.1
- **新增按钮/传感器**：在 `BTN` 参数表增加名称，或在 `STAT` 追加参数位
- **兼容性**：帧格式固定不变，命令允许增量添加

---

## 8. 实现建议

- **大脑（Python）**：`pyserial` 读串口，逐行解析；建议用状态机处理半行（粘包/断包）
- **小脑（Arduino）**：串口中断或 `Serial.available()` 循环 + 行缓冲；校验用 XOR 累加
- **调试**：文本协议可直接用串口监视器观察；两端各打印收发日志
