# 硬件接口设计 —— 引脚分配图（IO Map）

> 接口契约文档 · 干杯一号
> 版本：V0.1 · 最后更新：2026-08-06

---

## 1. 设计原则

1. **接口契约先行，器件型号后定** —— 先定"哪个口接什么"，再选具体买哪个型号。
2. **端口软件可配置** —— 代码中通过引脚映射宏定义，调整端口只改一处，不动逻辑。
3. **预留余量** —— 当前设计只用了约一半引脚，新功能随时可接入预留口。
4. **电平匹配明确标注** —— 3.3V / 5V 分清，避免烧板。

---

## 2. 电源架构（顶层）

```
电池 12V ──┬──► 电调 ──► 电机
            │
            └──► DC-DC 降压 5V/3A ──► 树莓派 4B
                                   └─► Arduino Mega（5V）
```

- 电池电压采样：A3 经分压电阻（约 10K:4.7K，12V → ~3.6V）
- 电池仓温度采样：A4 接 NTC 热敏电阻

## 3. 大脑 —— 树莓派 4B 引脚分配

| GPIO | 功能 | 方向 | 电平 | 说明 |
|---|---|---|---|---|
| GPIO14 (TXD) | UART 发送 → 小脑 | 输出 | 3.3V | 树莓派 → Arduino 可直连 |
| GPIO15 (RXD) | UART 接收 ← 小脑 | 输入 | 3.3V | ⚠️ 必须电平转换 |
| GPIO18 | 散热风扇 PWM | 输出 | 3.3V | OS 温控策略（gpio-fan） |
| GPIO2/3 | I2C | 双向 | 3.3V | 预留：传感器 / 扩展板 |
| GPIO8-11 | SPI | 双向 | 3.3V | 预留：扩展板 |
| CSI 接口 | 摄像头 | - | - | 行车记录 / 翻转 vlog |
| USB 口 | 4G 通信模块 | - | - | **必须**：对讲 / 定位上报 / APP 控制（可含 GPS） |
| USB 口 | GPS 定位模块 | - | - | **必须**：实时定位（优先选 4G+GPS 二合一） |
| USB 口 | 麦克风 | - | - | 语音唤醒 + 对讲录音（USB 麦克风或声卡） |
| 3.5mm 音频 | 功放 → 扬声器 | 输出 | - | 引擎轰鸣 + 对讲回放 + 语音助手回复 |
| 5V 引脚 | 风扇 / 外设供电 | - | 5V | 散热风扇电源 |

## 4. 小脑 —— Arduino Mega 2560 引脚分配

### 4.1 输入（传感器 + 按钮）

| 引脚 | 信号 | 类型 | 说明 | 关联 PRD |
|---|---|---|---|---|
| A0 | 油门踏板 | 模拟 | 左脚霍尔踏板 / 电位器 | F-DRV-01 |
| A1 | 刹车踏板 | 模拟 | 右脚霍尔踏板 | F-DRV-02 |
| A2 | 坐垫压力 | 模拟 | 就座检测 → 自动上下电 | F-PWR-01 |
| A3 | 电池电压 | 模拟(分压) | 电量显示 / 低压保护 | F-BAT-05 |
| A4 | 电池仓温度 | 模拟(NTC) | 过热保护 | NF-02 |
| A5 | 电机电流 | 模拟 | 过流 / 堵转保护 | NF-01 |
| D22 | 一键刹车 | 数字 | 红色大钮，最高优先级 | F-DRV-05 |
| D23 | 静音开关 | 数字 | 引擎轰鸣静音 | F-SND-03 |
| D24 | 大灯开关 | 数字 | 前大灯控制 | F-CON-02 |
| D25 | 灯带开关 | 数字 | RGB 灯带控制 | F-CON-03 |
| D26 | 喇叭按钮 | 数字 | 按下鸣笛 | F-CON-04 |
| D27 | 对讲按钮 | 数字 | 孩子按住说话 | F-TLK-02 |

### 4.2 输出（执行器 + 灯）

| 引脚 | 信号 | 类型 | 说明 | 关联 PRD |
|---|---|---|---|---|
| D9 | 电机油门 | PWM | → 电调信号线 | F-DRV-01 |
| D10 | 转向 | PWM | 舵机 / 转向电机 | F-DRV-03 |
| D2 | 前大灯 | 数字 | 经继电器/高边驱动 | F-LIT-01 |
| D3 | 刹车灯 | PWM | 亮度可调 | F-LIT-03 |
| D4 | 左转向灯 | 数字 | 经驱动 | F-LIT-04 |
| D5 | 右转向灯 | 数字 | 经驱动 | F-LIT-04 |
| D11 | RGB 灯带 | 数字 | WS2812B 数据线 | F-LIT-02 |

### 4.3 通信与预留

| 引脚 | 信号 | 说明 |
|---|---|---|
| D18/D19 | Serial1 | ←→ 树莓派 UART（主通信） |
| D16/D17 | Serial2 | 预留（GPS / 调试 / 其他） |
| D14/D15 | Serial3 | 预留 |
| D20/D21 | I2C | 预留（OLED 仪表等） |
| D50-53 | SPI | 预留 |
| D6/D7/D8/D12/D13 | 数字预留 | 新功能随时接入 |
| A6-A15 | 模拟预留 | 新传感器随时接入 |

## 5. 树莓派 ↔ Arduino 通信链路

```
树莓派 4B                     Arduino Mega
GPIO14 (TXD) ──────► 电平转换 ─► D19 (RX1)
GPIO15 (RXD) ◄────── 电平转换 ◄─ D18 (TX1)
```

- 通信方式：UART 串口，波特率 115200
- 协议定义：见 [communication_protocol.md](communication_protocol.md)
- ⚠️ **电平转换**：Arduino(5V) → 树莓派(3.3V) 方向必须经双向电平转换模块，否则烧毁树莓派 GPIO

## 6. 音频与语音子系统（大脑侧，不走 Arduino 引脚）

```
麦克风 ──► 语音识别（vosk 离线）──► 指令 ──► Arduino 执行（开灯/灯带等）
油门状态（Arduino A0 上报）──► 音效合成 ──► 功放 ──► 扬声器（轰鸣随油门）
家长 APP ──► 4G ──► 对讲回放 ──► 功放 ──► 扬声器
小孩对讲按钮(D27) ──► Arduino 上报 ──► 录音 ──► 4G ──► 家长 APP
```

| 输入/输出 | 硬件 | 说明 |
|---|---|---|
| 语音唤醒输入 | USB 麦克风 | 唤醒词"干杯出来"，离线识别 |
| 引擎轰鸣输出 | 功放 + 扬声器 | 油门越大音量越高，实时合成 |
| 对讲回放 | 功放 + 扬声器 | 家长语音播放 |
| 对讲录音 | USB 麦克风 | 小孩按住中控按钮录音上传 |
| 鸣笛声 | 功放 + 扬声器 | 喇叭按钮触发 |

- 音频管理：树莓派软件混音（ALSA/pulseaudio），统一管理音效、对讲、语音助手三种音源
- 静音开关（Arduino D23）上报后，树莓派软件静音所有音源

---

## 7. 4G 通信与 GPS（必选基础设施）

- **4G 模块**：USB 接口，负责对讲、定位上报、APP 远程控制
- **GPS 模块**：优先选 **4G+GPS 二合一**模块（如 SIM7600 / EC200 系列），一个 USB 口解决两件事
- 定位数据流：GPS → 树莓派 → 4G 上传 → 家长 APP 地图显示
- 对讲数据流：见第 6 节
- 断网降级：4G 断开时，本地驾驶功能不受影响（踏板/灯光/急刹走 Arduino 本地逻辑）

---

## 8. 安全设计要点

1. **一键刹车双保险**：D22 软件急刹 + 按钮电路**直连电调使能端**做硬件急停。程序失效时，按下按钮仍能断电。
2. **大电流设备隔离**：灯、电机一律经继电器/驱动电路，绝不直接接 GPIO。
3. **保护采样**：电池电压（A3）、温度（A4）、电流（A5）三路保护信号齐全。
4. **树莓派散热**：散热片 + GPIO18 PWM 温控风扇。

---

## 9. 端口调整策略

- 调整端口 = 修改代码中的**引脚映射宏定义**，逻辑层无需改动
- 新功能优先接入**预留端口**（4.3 节）
- 引脚分配必须**同步更新本文档**，保持契约一致
